# SWE 2021 · Two Sum

A Python implementation of Two Sum using a nested-loop search over pairs of indices.

**Focus:** Python  
**Status:** Coursework exercise

## Repository guide

| Path | Purpose |
| --- | --- |
| [main.py](main.py) | Two Sum function and three example calls |
| [forgettenfile](forgettenfile) | Additional practice text |

## Getting started

```sh
python3 main.py
```

The included examples return `[0, 1]`, `[1, 2]`, and `[0, 1]`.

## Notes

The search takes O(n²) time and O(1) auxiliary space. If no pair is found, this implementation returns `0`.
